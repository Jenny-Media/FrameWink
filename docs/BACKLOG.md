# Post-MVP backlog

Items in this file are intentionally excluded from the 40-hour MVP. Do not move
one into active work without an explicit decision and revised time budget.

## Curation improvements

- iPadOS 18+ native image-aesthetics scoring behind availability checks.
- Evaluate a compact custom Core ML aesthetics model for iPadOS 15–17.
- Richer feedback such as `Show More Like This`.
- Better event clustering and nostalgia/recency controls.
- Optional semantic category balance.
- Additional collage templates beyond the responsive pair/stack and bounded
  four-photo Mosaic.

## Sources and integrations

- Evaluate a narrower iPhone companion workflow only if portable full-frame use
  proves insufficient; the current universal release already supports compact
  iPhone playback.
- Files and external drives.
- SMB, WebDAV, Nextcloud, NAS, and Immich.
- iCloud Shared Albums behavior beyond the initial PhotoKit source.
- Shortcuts/App Intents.
- Home Assistant or managed-device integration.
- Apple TV companion.

## Media and presentation

- Live Photos and video.
- Music.
- Clock/calendar overlays.
- Optional weather, with an explicit privacy/network tradeoff.
- Additional transitions and themes beyond the restrained dissolve and subtle
  single-photo motion used by the default frame.
- Photographer color-management options.

## Operations

- Managed/supervised Single App Mode documentation.
- Mount-maker partnerships and device/mount compatibility directory.
- Localized App Store pages and app strings.
- Additional legacy-device test coverage.
- Public source release, license, contribution guide, trademark policy, and
  reproducible-build documentation.

## Explicitly rejected unless platform capability changes

- Claiming normal public access to ambient-light lux.
- Camera-based continuous light metering.
- Claiming guaranteed consumer auto-relaunch after reboot.
- Background-audio or location hacks for process survival.
- Accessing Apple Photos private Memories/Featured Photos ranking.
